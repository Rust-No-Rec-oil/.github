## 🚀 Why Choose Rust No Recoil?

Rust spray patterns differ by gun, and a single global strength never fits them all. This tool keeps a separate profile for each weapon, with vertical and horizontal values tuned independently. ADS and hip-fire behavior are separated too.

Sensitivity scaling means a setup built on one mouse can still work on another without rebuilding every value.

5. Save the values and repeat for other weapons.
